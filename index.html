Google OAuth Setup Guide

  1. 1 Go to Google Cloud Console and create a new project
  2. 2 Enable the Google Calendar API in APIs & Services → Library
  3. 3 Create OAuth 2.0 Credentials (Web Application type). Add http://localhost:8000/api/google/callback as Authorized Redirect URI
  4. 4 Copy your Client ID and Client Secret and add to c.env:
    GOOGLE_CLIENT_ID=your_client_id
    GOOGLE_CLIENT_SECRET=your_client_secret
  5. 5 Restart the server and click Sign in with Google
